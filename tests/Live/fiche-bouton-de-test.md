# Fiche Hector : le bouton de test d'un dispositif différentiel

## Rôle du bouton de test

Le bouton de test, marqué « T » ou « Test », provoque volontairement une fuite de courant à l'intérieur du dispositif. Il permet de vérifier que le mécanisme de déclenchement fonctionne.

## Ce que l'usager peut faire

| Geste | Résultat attendu |
|---|---|
| Appuyer une fois sur le bouton de test | Le dispositif déclenche : sa manette s'abaisse |
| Relever la manette | Le courant revient |

Si le dispositif ne déclenche pas quand on appuie sur le bouton de test, il faut le faire contrôler par un électricien.

## Limites du bouton de test

Le bouton de test vérifie le mécanisme de déclenchement. Il ne mesure ni le seuil ni le temps de déclenchement : seul un appareil de mesure, utilisé par un électricien, le fait.
