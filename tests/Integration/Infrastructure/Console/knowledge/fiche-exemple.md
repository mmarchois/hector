# Fiche d'exemple : dispositif différentiel

Fiche fictive, écrite pour les tests d'ingestion. Elle n'a aucune valeur technique.

## Rôle

Un dispositif différentiel compare le courant qui part et celui qui revient.

Un écart signale une fuite de courant vers la terre.

## Vérifications

| Geste | Qui | Remarque |
|---|---|---|
| Appuyer sur le bouton de test | Usager | Le dispositif doit déclencher |
| Réarmer après un déclenchement | Usager | Une seule fois |
| Ouvrir le tableau | Électricien | Jamais par l'usager |

### Article 1 — Bouton de test

Le bouton de test vérifie le mécanisme de déclenchement.

## Limites

Cette fiche ne remplace pas une vérification par un électricien.
